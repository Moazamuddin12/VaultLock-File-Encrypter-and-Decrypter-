Lock your files on your own machine.

VaultLock turns files and folders into authenticated .vault containers using modern encryption, with no account, no cloud and no telemetry. Preview inside without writing anything to disk, then shred the originals once the vault is proven good.

Everything you need, nothing you do not

Built for people who want real encryption without learning a command line, and for developers who want to read exactly how it works.

Authenticated encryption

AES-256-GCM or ChaCha20-Poly1305. Wrong passwords and any tampering are caught before a byte of plaintext is released.

Password + keyfile

Add a random keyfile as a second factor. Guesses cannot even be tested without it.

Files and whole folders

A folder becomes one vault, streamed straight into the encryptor with no plaintext temp file.

Secure viewer

Preview images, PDFs, audio, video and text decrypted in memory only. Nothing is written to disk.

Safe shredder

1, 3 or 7 overwrite passes. It only runs after the new vault is re-read and every block authenticates.

Live progress

Percent, MB/s and ETA on a single dial. Cancel any time and your originals stay untouched.

Strength meter

A pattern-aware estimate that spots dictionary words, leetspeak, keyboard walks and dates. Plus a passphrase generator.

CLI included

The same engine for scripts: lock, unlock, verify, inspect, rekey, shred, keygen.

Fully offline

No CDN, no web fonts, no analytics. It runs on 127.0.0.1 and reaches nothing else.

How it works

Three steps in the app. Underneath, every vault follows the same careful pipeline.

  1. Drop files or add a folderDrag onto the dial or pick them from the built-in browser.
  2. Choose a passwordWatch the strength meter. Optionally require a keyfile and shred the originals afterwards.
  3. Press LockVaultLock writes the vault, re-reads it to prove it opens, then (if you asked) shreds the originals.

The safe pipeline

Derive key (Argon2id)→ Stream-encrypt in 1 MiB chunks→ Write hidden .partial→ Flush to disk→ Publish atomically→ Re-read and verify→ Shred originals (optional)

Specifications

The full byte-level container format is in docs/FORMAT.md in the repository.

CiphersAES-256-GCM, ChaCha20-Poly1305 (256-bit keys, 96-bit nonces, 128-bit tags)
Key derivationArgon2id: standard 3 passes / 64 MiB, strong (default) 4 / 256 MiB, paranoid 6 / 1 GiB. Or PBKDF2-SHA256 at 1,000,000 iterations
Key schedulePassword (NFKC) or HMAC with a keyfile digest, then KDF, then HKDF-Expand into separate encryption and MAC keys
Salt and nonceFresh random 32-byte salt and 12-byte nonce base per vault; per-chunk nonce = base XOR chunk index
Container100-byte plaintext header, one sealed metadata block, then sealed data chunks
IntegrityEach chunk authenticates the whole header, its index and a last-chunk flag, so reordering, truncation and appended data are detected
Chunk size1 MiB default (4 KiB to 16 MiB allowed)
MetadataFile name, kind and size are encrypted in a fixed 4096-byte padded block
Local server127.0.0.1 only, random port, per-launch token, strict Host and Origin checks, CSP script-src 'self'
ThroughputAES-256-GCM 355 / 454 MB/s encrypt / decrypt; ChaCha20-Poly1305 450 / 480 MB/s (2-core cloud VM)
RuntimePython 3.11 to 3.13 · cryptography, Flask, argon2-cffi

Where it is useful

Anywhere a file should stay private if it is lost, copied or backed up somewhere you do not fully trust.

Personal documents

IDs, tax records, contracts, medical files and recovery codes.

USB sticks and transfers

Carry or send files knowing a lost drive reveals nothing.

Cloud and external backups

Lock a folder before it goes to storage you do not control.

Students and freelancers

Protect coursework and client work on shared or lost laptops.

Run it in two minutes

You need Python 3.11 or newer from python.org. On Windows, tick “Add python.exe to PATH” in the installer.

# 1. get the code
git clone https://github.com/Moazamuddin12/VaultLock.git
cd VaultLock

# 2. start it
.\start_vaultlock.bat        # Windows (or just double-click it)
sh start_vaultlock.sh        # macOS / Linux

The launcher builds its own environment on the first run and opens VaultLock in your browser. Or install it as a command:

pip install "git+https://github.com/Moazamuddin12/VaultLock.git"
vaultlock gui

Honest about its limits

Security tools should say what they cannot do. VaultLock has not had an independent audit.

It protects

  • Vaults that are stolen, copied or leaked
  • Backups stored on untrusted media
  • Against anyone without your password (and keyfile)

It cannot protect

  • A PC with malware or a keylogger
  • A forgotten password or lost keyfile (no recovery)
  • Reliable shredding on SSDs or synced folders
  • Traces the operating system keeps, like thumbnails
